# 🎓 Student Learning Hub

A modern, beginner-friendly web portal built to guide students through programming fundamentals step-by-step.

---

## 📌 Project Overview

**Student Learning Hub** is a structured web application created to simplify the coding journey for computer science and engineering students. It provides an intuitive roadmap for core computer science languages, an interactive registration workflow, and curated video learning resources.

---

## ✨ Features & Functionalities

*   **📊 Learning Roadmap Matrix (`index.html`)**
    *   Clean overview of programming topics with live progress statuses (HTML, C Language, CSS, JavaScript, C++).
    *   Quick navigation links and learning journey visuals.

*   **📝 Student Registration Portal (`signup.html`)**
    *   Full-featured registration form capturing student details: Name, Email, Password.
    *   Custom selection inputs for Gender, Academic Year (1st to 4th Year), Branch (CSE, IT, ECE, Mechanical), and Interest Checkboxes (C++, DSA, Web Dev, AI/ML).

*   **🎬 Media & Resource Center (`video.html`)**
    *   Embedded YouTube media player for direct tutorial viewing.
    *   Handpicked external course links for HTML, CSS, JavaScript, and C++.

*   **🎨 Custom Responsive Design (`style.css`)**
    *   Unified ocean-blue theme with soft-shadow card components.
    *   Flexbox-driven layout for forms and responsive media assets (`iframe`, `img`).
